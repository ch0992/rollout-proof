## Issue 생성 규칙

Issue는 dependency graph 순서에 따라 생성한다. 문서가 존재한다는 이유만으로 모든 Task를 동시에 Ready로 만들지 않는다. 선행 Task가 PASS일 때 dependent Issue를 Ready로 전환한다.
